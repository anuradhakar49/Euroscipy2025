## Overview
The **Compliance Checker** is a Retrieval-Augmented Generation (RAG) powered tool designed to automatically evaluate AI/ML workflows against relevant regulatory and ethical guidelines such as **GDPR**, **HIPAA**, and the **EU AI Act**. In addition 

It integrates seamlessly with existing machine learning pipelines to:
- Perform **automated compliance checks** using structured regulation knowledge bases.
- Enhance **traceability** with audit trails and decision logs.
- Support **bias auditing**, **explainability**, and **reproducibility** in model development.

This project is designed for **developers, compliance officers, and AI researchers** aiming to embed **trust, accountability, and transparency** into AI systems from the start.

---

## Key Features
- **RAG Architecture** → Combines document retrieval from compliance knowledge bases with generative LLM reasoning.
- **Multi-Regulation Coverage** → Preloaded with GDPR, HIPAA, and AI Act Articles & Recitals.
- **Healthcare-Focused Use Case** → Includes a heart disease prediction dataset for ML model testing.
- **Explainability Integration** → Supports SHAP-based explanations for decisions.
- **Bias Auditing** → Flags fairness concerns in model outputs.
- **Extensible** → Easily adapt to finance, manufacturing, autonomous systems, and other domains.
